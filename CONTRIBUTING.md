# Contributing to AgentLint

Thank you for your interest in contributing to AgentLint!

This project is currently in active development as part of the IBM Bob 2.0 Hackathon.
Full contribution guidelines will be added after the initial release. In the meantime,
please open an issue or pull request and we'll review it promptly.

## Development Setup

```bash
git clone <repo-url>
cd AgentLint
pip install -e ".[dev]"
pytest
```

## Code Style

Follow existing conventions. Keep external dependencies minimal (see `AgentLintplan.md` §22).
