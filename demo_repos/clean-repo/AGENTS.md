# AGENTS.md

This file instructs AI coding agents on how to work in this repository.

## Package Manager

Use pnpm to install and manage dependencies:

```bash
pnpm install
```

## Build

Build the project with:

```bash
pnpm run build
```

## Test Command

Run the test suite with Vitest:

```bash
pnpm run test
```

## Lint

Lint the source code with ESLint:

```bash
pnpm run lint
```

## Project Structure

- `src/` — application source code
- `dist/` — build output (generated, do not edit)

## Notes

- Node.js 20 is required
- Always run `pnpm run lint` and `pnpm run test` before committing
